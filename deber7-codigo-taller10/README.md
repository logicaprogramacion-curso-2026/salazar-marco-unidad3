# Taller 10 - Sistema de Gestión Académica

## Descripción
Sistema desarrollado para la gestión académica de estudiantes, permitiendo el registro de estudiantes, notas, cálculo de promedios y generación de reportes.

## Requisitos del Sistema
- Python 3.7 o superior
- Sistema operativo: Windows, Linux o macOS

## Estructura del Código
- `main.py`: Archivo principal que ejecuta el programa
- `estudiantes.py`: Gestión de estudiantes
- `notas.py`: Gestión de notas académicas
- `utils.py`: Funciones de utilidad
- `config.py`: Configuraciones del sistema

## Funcionalidades
1. Registrar estudiantes
2. Consultar estudiantes por cédula
3. Listar todos los estudiantes
4. Registrar notas por asignatura
5. Consultar notas de un estudiante
6. Calcular y mostrar promedios generales
7. Generar reporte estadístico
8. Salir del sistema
