## Descripción del Proyecto
Este proyecto implementa un sistema interactivo de consola para la gestión de ventas e inventario en una tienda, haciendo uso de estructuras de datos nativas (tuplas, diccionarios, listas) y librerías especializadas en análisis de datos (`pandas`, `numpy`, `matplotlib`).

## Estructura de Entregables
- `main.py`: Código ejecutable en Python.
- `minitienda.ipynb`: Notebook con ejecuciones paso a paso.
- `informe_minitienda.pdf`: Reporte técnico con evidencias de funcionamiento y membrete institucional.
- `ventas.csv`: Archivo de datos persistentes con transacciones registradas.
- `log.txt`: Archivo de registro de eventos y excepciones.
- `ingresos.png`: Imagen del gráfico de barras generado.

## Retos Cumplidos
- **Reto A:** Inclusión dinámica de nuevos productos al catálogo y actualización de inventario.
- **Reto B:** Exportación del gráfico de ingresos a formato PNG mediante `plt.savefig()`.
- **Reto C:** Aplicación automática del 5% de descuento para ventas con 10 o más unidades.
- **Reto D:** Validación de IDs inexistentes e inclusión de log de intentos fallidos en `log.txt`.
